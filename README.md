# คิดครบ — All-in-one Calculator

เว็บเครื่องคิดเลขครบวงจรในหน้าเดียว ตั้งแต่เครื่องคิดเลขพื้นฐาน สถิติ เรขาคณิต การเงิน แปลงหน่วย สุขภาพ ไปจนถึงวันและเวลา

สร้างด้วย HTML, CSS และ JavaScript ล้วน ไม่ต้องติดตั้งอะไร เปิดไฟล์แล้วใช้งานได้ทันที

> สถานะ: **v0.2 (กำลังพัฒนา)**

## ฟีเจอร์ที่ใช้งานได้แล้ว

### พื้นฐาน
- บวก ลบ คูณ หาร ยกกำลัง วงเล็บ ทศนิยม
- `π`, `e`, `√`, `sin`, `cos`, `tan` (ใช้องศา), `log`, `ln`, แฟกทอเรียล `!`
- เติมวงเล็บปิดที่ขาดให้อัตโนมัติ, พิมพ์ผ่านคีย์บอร์ดหรือกดปุ่มได้

### คณิตศาสตร์
- **สถิติ**: จำนวนข้อมูล, ผลรวม, ค่าเฉลี่ย, ฐานนิยม, มัธยฐาน, Q1–Q3, IQR, ต่ำสุด/สูงสุด, outliers
- **อนุกรม**: เลขคณิต และเรขาคณิต (พจน์ที่ n และผลรวม)
- **เปอร์เซ็นต์**: a% ของ b, ส่วนลด/กำไร, เปอร์เซ็นต์เปลี่ยนแปลง, a เป็นกี่ % ของ b
- **สมการ**: กำลังสอง, เส้นตรง, 2 ตัวแปร, สัดส่วน a/b = c/d
- **จำนวนเต็ม**: GCD/LCM, nPr/nCr, ตรวจจำนวนเฉพาะพร้อมตัวประกอบ

### เรขาคณิต
- **รูปทรง**: ลูกบาศก์, ปริซึม, พีระมิด, พีระมิดตัด, กรวย, กรวยตัด, ทรงกระบอก, ทรงกลม, ส่วนของทรงกลม, ทรงรี
- **รูปร่าง**: สามเหลี่ยม, สามเหลี่ยมมุมฉาก, สี่เหลี่ยมต่าง ๆ, รูปหลายเหลี่ยมด้านเท่า, วงกลม, ส่วนโค้ง, วงรี
- บังคับให้ใส่ค่าความยาวเป็นจำนวนบวกเท่านั้น

### การเงิน
- ราคาต่อหน่วย, ภาษี, ทิป
- เงินกู้แบบผ่อนชำระ, ดอกเบี้ยเงินฝาก (คงที่ / ทบต้น)
- แปลงสกุลเงิน 20 สกุล ดึงอัตราล่าสุดจาก [Frankfurter API](https://frankfurter.dev) และมีอัตราสำรองเมื่อออฟไลน์

### แปลงหน่วย
ความยาว, น้ำหนัก, เวลา, พื้นที่, ปริมาตร, ความเร็ว, ความเร่ง, แรง, ความดัน, ข้อมูล, มุม, อุปกรณ์ทำอาหาร, การถ่ายโอนข้อมูล, ฐานเลข, เลขโรมัน

### สุขภาพ
BMI, BMR/TDEE (Mifflin–St Jeor), โซนหัวใจสำหรับวิ่ง

### วันและเวลา
คำนวณอายุ, บวก/ลบวัน, ช่วงเวลาระหว่างสองวัน, นับถอยหลัง

### ทั่วไป
- ธีมมืด / สว่าง
- ค้นหาหมวดเครื่องมือ
- รองรับมือถือ (responsive)

## วิธีใช้งาน

```bash
เปิดลิ้ง https://nlhtwolf2008-design.github.io/All-In-One-Calculator-/
```

ในเบราว์เซอร์ได้เลย

```bash
git clone https://github.com/<username>/<repo>.git
cd <repo>
```

จากนั้นเปิด `index.html` ในเบราว์เซอร์ได้เลย หรือถ้าต้องการรันผ่านเซิร์ฟเวอร์ในเครื่อง:

```bash
python3 -m http.server 8000
# เปิด http://localhost:8000
```

## โครงสร้างโปรเจกต์

```
├── index.html   # โครงหน้าเว็บ
├── styles.css   # สไตล์และธีม
├── app.js       # ตรรกะหลักของทุกหมวด
└── extras.js    # ส่วนเสริม: เครื่องคิดเลข, รูปทรง, กลุ่มหน่วยเพิ่มเติม
```

## สิ่งที่ยังอยู่ในแผน

- [ ] สลับภาษาไทย / อังกฤษ (ตอนนี้มีตัวเลือกบนหน้าเว็บแล้วแต่ยังไม่ทำงาน)
- [ ] ธีม "ตามระบบ" (ตอนนี้มีมืด/สว่าง)
- [ ] แปลงสกุลเงิน: เลือกคู่สกุลเงินนอก Top 20 และตาราง Top 20
- [ ] เรขาคณิต: ห้าเหลี่ยม/หกเหลี่ยม/แปดเหลี่ยมแบบเดี่ยว, มุมของสามเหลี่ยม, ความสูงครบทุกด้าน, สามเหลี่ยมมุมฉากแบบกรอกมุม
- [ ] สุขภาพ: เลือกหน่วยเมตริก/อิมพิเรียล และ lifestyle แบบละเอียด
- [ ] วันและเวลา: รองรับการกรอกเวลา
- [ ] Physics (ไอเดีย)

## หมายเหตุ

ผลลัพธ์ทั้งหมดใช้เพื่อการคำนวณเบื้องต้นเท่านั้น ค่าด้านสุขภาพไม่ใช่คำวินิจฉัยทางการแพทย์ และอัตราแลกเปลี่ยนอาจต่างจากอัตราจริงของธนาคาร
